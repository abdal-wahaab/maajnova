# Maajnova

Marketing site for **Maajnova** — a Nairobi software studio building AI automation,
custom software and business & healthcare platforms, with the hardware to run them
and the training to own them. Flagship product: **Maaj Health** (in active development).

## Pages
- `index.html` — Home
- `services.html` — Services
- `maajhealth.html` — Maaj Health
- `about.html` — About

Static site (HTML/CSS/JS, no build step). Fonts, icons (Lucide) and GSAP load from CDNs;
photos load from Unsplash. Just open `index.html`, or deploy the folder to any static host
(Netlify, Cloudflare Pages, GitHub Pages).
